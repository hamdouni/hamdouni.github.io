Sunday, October 27, 2019 · 1 minute · 31 words

Install LTS Hardware Enablement Stack

1sudo apt-get install --install-recommends linux-generic-hwe-18.04 xserver-xorg-hwe-18.04

Clean

1sudo apt purge --autoremove

Reboot to load new kernel

1reboot

After boot, check your new kernel version

1uname -a
