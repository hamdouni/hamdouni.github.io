Increase wordpress max file upload size

Friday, December 5, 2014 · 1 minute · 20 words

On Ubuntu/Debian distro, edit the /etc/wordpress/htaccess and add this lines :

1php_value upload_max_filesize 50M
2php_value post_max_size 50M
3php_value memory_limit 50M
